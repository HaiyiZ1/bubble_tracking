# Phase 1 复现策略说明（中文）

## 背景与目标
我们的目标是为“液体电池中的气泡追踪（包含分裂/合并/新生/消失）”建立可落地的技术路线。前期被要求“复现一个满足全部标签的研究”，即：
- 使用 **SAM2**
- **细胞边界**/生物医学场景
- **动态视频**或时序追踪
- 公开数据 + 可复现代码
- 对分裂/合并等事件有明确处理

## 为什么“完全匹配的复现”不现实
经调研发现，当前公开文献中 **很难找到同时满足以上全部标签** 的工作，主要原因：
1. **SAM2 文献多集中在静态/体数据分割**，并非严格的时序追踪。
2. 细胞/生物医学的“视频级追踪”研究通常 **不基于 SAM2**。
3. 即便是“动态/视频”场景，多数工作也 **不覆盖 split/merge 事件建模**。
4. 现有公开代码/数据通常面向 GPU 规模化评测，**CPU 复现不可比**，结果参考价值有限。

因此，强行复现一个“完全匹配标签”的论文，成本高、收益低，且难以回答我们真正关心的工程问题。

## 调研到的“部分匹配”文献（以及未采用原因）
以下是调研时发现的“满足部分标签”的方向，但均无法完整覆盖我们的需求：

1. **Medical SAM2 / Biomedical-SAM2 类工作**
   - 满足：SAM2 + 医学数据
   - 不足：主要是 2D/3D 静态分割或跨切片传播，**不是细胞视频追踪**
   - 原因：无法直接验证“分裂/新生/消失”的 tracking 逻辑

2. **细胞追踪挑战（CTC）相关研究**
   - 满足：细胞边界 + 动态追踪
   - 不足：多数 **不基于 SAM2**，或缺少公开 SAM2 复现代码
   - 原因：很难在 SAM2 框架下直接复现并形成可比结果

3. **SAM2 原始 VOS 基准（DAVIS / YouTube-VOS）**
   - 满足：SAM2 + 时序传播
   - 不足：非生物医学，**目标形态/事件机制差异大**
   - 原因：只能验证 pipeline 是否工作，**对细胞/气泡的动态特性帮助有限**

## 为什么“复现论文”不如想象中有帮助
- **复现并不能解决分裂/合并问题**：这是气泡追踪的核心难点，但多数论文并未建模。
- **结果不可比**：硬件、模型规模、数据处理流程不同导致指标失真。
- **工程价值更低**：我们需要尽快验证“能否集成、能否跑通、在哪些场景会失败”。

## 实际采用的策略（更贴近目标）
我们选择 **直接用 SAM2 在 CTC HeLa 细胞序列上跑通管线**，原因：
- CTC HeLa 是公开、典型的“动态细胞边界”数据
- 能直接暴露 **追踪崩溃、分裂/新生缺失、需要重提示** 等关键问题
- 更接近后续气泡追踪场景的真实挑战

这一步验证的不是“论文指标”，而是**工程可行性与失败模式**。

## 当没有合适数据时的替代验证
在缺乏匹配数据的阶段，我们还制作了 **合成数据（多个圆形目标动态移动/分裂）** 来验证：
- Prompt → 传播 → 输出 → 可视化 → 统计 的全链路可运行
- 确认了输出格式与追踪结构能支撑后续逻辑

## 结论
- “复现符合全部标签的研究”在当前阶段 **不现实且收益有限**。
- 选择 CTC HeLa + 合成数据的策略，**更快、更贴近目标问题**。
- 后续重点应放在：**自动 prompt 生成、split/merge 事件处理、失败重初始化**，而不是追求论文指标复现。

## 今日结论（2026-02-04）
- **SAM2 可用于 prompt 生成**，初步效果良好，能在关键帧上较稳定地发现气泡并给出可用 mask。
- **SAM2 在“追踪”上不稳定**：能分割出气泡，但跨帧持续跟踪容易断裂或偏移，说明仅靠 SAM2 自带传播不足以支撑本任务。
- **下一步方向明确**：在关键帧用 SAM2 自动生成 prompt/掩码，随后交由我们自己的 **重提示 + 追踪算法**（基于 mask 的匹配与事件处理）完成连续跟踪。
